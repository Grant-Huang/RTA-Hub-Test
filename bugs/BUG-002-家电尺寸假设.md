# BUG-002: 家电尺寸自动假设

## 问题概述

| 属性 | 值 |
|------|-----|
| **Bug ID** | BUG-002 |
| **严重程度** | High |
| **测试场景** | 场景一：标准 L 型厨房 |
| **测试模式** | 被动式用户 |
| **相关测试日志** | `Scenario-1/conversation.html` |

## 问题描述

用户选择家电类型后，在用户未提供具体尺寸的情况下，系统自动假设了家电尺寸（Refrigerator=33", Range=30" 等），并将这些假设值放入 Confirmation Panel。

## 复现步骤

1. 打开测试网站 http://rta-hub.inkpath.cc
2. 创建新对话
3. 选择 "L-shape" 布局
4. 点击选择家电类型 (Refrigerator, Range, Range hood, Dishwasher)
5. 点击 "Done / none needed"
6. 观察 Confirmation Panel

## 用户实际输入

点击选择了以下家电类型（仅选择类型，**未提供具体尺寸**）：
- Refrigerator
- Range
- Range hood
- Dishwasher

## 系统自动假设的信息

| 家电 | 系统假设尺寸 | 状态 |
|------|-------------|------|
| Refrigerator | 33" | assumed |
| Range | 30" | assumed |
| Range hood | 30" | assumed |
| Dishwasher | 24" | assumed |

## AI 行为

系统在用户选择家电类型后，自动假设了常见尺寸放入 Confirmation Panel，但没有明确告知用户这是假设值。

## 预期行为

选择家电类型后，系统应该：
1. **询问**具体尺寸（如 "请问您的冰箱是多大的？"）
2. **不要自动假设**尺寸放入 Confirmation Panel
3. 或者明确标注为"默认/假设值"，并引导用户确认

## 实际行为

自动使用常见尺寸填充 Confirmation Panel，标记为 "assumed"。

## 与 BUG-001 的关联

BUG-001 和 BUG-002 都属于**模板假设问题**：
- BUG-001: 布局尺寸模板假设
- BUG-002: 家电尺寸模板假设

## 建议修复方案

1. 用户选择家电类型后，弹出询问具体尺寸的选项
2. 不要自动填充假设值到 Confirmation Panel
3. 如果需要默认值，应该明确标注为"默认值"而非"用户输入"
